### Multi-Branch Network with OSPF
**Folder:** [`Multi-Branch Network`](./Multi-Branch%20Network) · **Details:** [AboutProject.md](./Multi-Branch%20Network/AboutProject.md)

A three-site network for Nairobi (HQ), Mombasa and Kisumu. The sites are connected in a triangle of routers that learn each other's networks automatically using OSPF. If one WAN link goes down, traffic reroutes through the third site.

**Skills shown:** IPv4 subnetting (/24 and /30), router configuration, single-area OSPF, passive interfaces, link-failure recovery, routing verification.

**Tools:** Cisco Packet Tracer 8.2.2 · 3× Cisco 2911 routers · 3× Cisco 2960 switches · 3× PCs
